# Four-lepton validation cards

This directory contains command cards, not generated events. Run them from a
disposable work directory; preserve resulting logs separately.

The direct `h > e+ e- e+ e-` and `h > e+ e- mu+ mu-` surveys determine the
relative LO channel fractions at `mH=125.09 GeV`. The coherent and continuum
`gg_4l` cards compare the omitted signal–continuum interference near the peak;
they are not part of the nominal background sum.

Measured survey and forced-decay checks are recorded once in
[VALIDATION.md](../../VALIDATION.md). Numerical checks of event-weight
propagation do not establish closure of accelerated heavy-flavour samples.
